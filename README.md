# Wealthify

### Description

It is a comprehensive cryptocurrency portfolio management tool designed to help users track real-time prices, manage their digital asset portfolios, and maintain a wishlist of cryptocurrencies for potential investment. Built with **SwiftUI** for a modern user interface, **Core Data** for data persistence, and **Firebase** for secure account management, this app streamlines cryptocurrency tracking and planning.

## Features

- **Real-Time Crypto Tracking:** Provides up-to-date price data for a wide range of cryptocurrencies.
- **Portfolio Management:** Create and manage multiple portfolios to track holdings and monitor performance.
- **Wishlist Functionality:** Maintain a watchlist of cryptocurrencies and track their price movements.
- **Secure Account Management:** Integrated with Firebase Authentication to support email/password sign-in.
- **Detailed Coin Information:** Displays market data such as market cap and trading volume.
- **User-Friendly Interface:** Intuitive design using SwiftUI for seamless navigation.
- **Data Persistence:** Core Data ensures all user data (portfolios, watchlists) is securely stored locally.

## Tech Stack

- **SwiftUI**: For building the user interface.
- **Core Data**: For local data storage and persistence.
- **Firebase**: For user authentication and account management.
